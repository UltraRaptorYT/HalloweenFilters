# Halloween Camera Booth

A browser camera experience for previewing Halloween looks live and capturing portraits at parties and events.

## Language

**Filter**:
A selectable visual treatment applied to the camera view before a photo is captured.
_Avoid_: Lens, effect

**Makeup filter**:
A filter that keeps a person's face recognizable while adding believable makeup or prosthetic details.

**Transformation filter**:
A filter that changes the person's full-face appearance into a character while following their live expressions.

**Live preview**:
The camera view with the selected filter visible as the person moves.
_Avoid_: Final photo

**Captured photo**:
A still image taken from the live preview.
_Avoid_: Snapshot

**Photo review**:
The step after capture where guests can keep the photo or retake it before sharing.

**Offline capture**:
A photo taken without an internet connection and kept on the booth device until it can upload.

**Share QR**:
A scannable code that opens a captured photo on another device.

**Event booth**:
A shared camera station where event guests capture portraits and retrieve them by QR code.

**Event host**:
The person responsible for managing the booth and its shared photos.

**Host PIN**:
A private code the event host uses to manage that event's shared photos.

**Group photo**:
A captured photo with up to five guests, with the same selected filter applied to each person.

**Photo retention**:
How long a captured photo remains available before someone deletes it.
